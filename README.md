Rario is an interactive clinical communication simulator built for medical students to practice the **G-I-PD-D partnership communication model** (Greeting → Invite → Diagnosis Delivery → Discuss & Management) alongside empathy-based soft skills, through a pre-marital counseling case study centered on Rhesus incompatibility.

## Overview

The application places the user in the role of a physician conducting a pre-marital health consultation with a simulated patient. All patient responses are generated by a deterministic, rule-based dialogue engine that tracks conversation stage and detects relevant clinical and empathetic cues — no external API dependency, running entirely client-side in the browser.

## Features

- **Simulated patient chat** — the student, acting as the physician, converses with a simulated patient who responds according to a clinically validated reference script.
- **Rule-based dialogue engine** — patient responses are computed through keyword detection and conversation-stage tracking, requiring no external API or network connection.
- **Automated scoring** — two rubrics are evaluated immediately after each session:
  - **Communication skills**: Greeting (20%), Invite (30%), Diagnosis Delivery (20%), Discuss & Management (30%)
  - **Empathy skills**: active listening, perspective-taking, emotional responsiveness, patient-centered perspective, expressed support
- **Timed sessions** — each session runs for a maximum of 25 minutes, mirroring OSCE examination conditions.
- **Instructor dashboard** — a password-protected view for reviewing aggregated student scores.

## Technical Notes

Built as a single self-contained HTML/CSS/JavaScript file with no build step or framework dependencies, runnable directly in any modern browser. For real classroom deployment, the scoring backend integrates with **Google Apps Script and Google Sheets** as a lightweight, serverless data store.

## About This Demo Build

This repository contains a **portfolio-specific build**. Backend credentials (the Google Sheets connection) have been intentionally removed for data security, so the instructor dashboard on this demo only reflects locally stored session data in the visitor's own browser, rather than any live classroom data.

## Background

Developed as a clinical communication training tool for the Faculty of Medicine, Universitas Surabaya (Ubaya). The dialogue script and scoring rubric were designed around partnership-based communication and shared decision-making principles applied to pre-marital genetic counseling.
